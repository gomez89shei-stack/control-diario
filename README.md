# Caja Diaria

App web instalable para control de gastos diarios. Sitio estático: no necesita build ni configuración.

## Subir a GitHub y Vercel
1. Creá un repositorio nuevo en github.com y subí todos los archivos de esta carpeta (index.html, manifest.json, sw.js, icon-192.png, icon-512.png).
2. En vercel.com entrá con tu cuenta de GitHub, elegí "Add New > Project" e importá el repositorio.
3. Dejá todo por defecto (Framework: Other) y tocá "Deploy". En un minuto tenés tu link.

## Instalar en el celular
- Android (Chrome): menú ⋮ > Instalar app.
- iPhone (Safari): Compartir > Agregar a pantalla de inicio.

Los datos se guardan en el celular de quien la usa. Usá "Guardar respaldo" de vez en cuando.
